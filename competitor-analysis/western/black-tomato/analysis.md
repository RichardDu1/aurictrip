### 叙事结构 -- Episode（剧集）格式

**Episode 1 -- An arrival in Amalfi**
抵达那不勒斯，入住 Anantara Convento di Amalfi（13世纪悬崖修道院），探索 Amalfi 和 Atrani 村庄（Ripley 首次遇见 Dickie Greenleaf 之地），柠檬树下午餐。

**Episode 2 -- Capri and chiaroscuro**
私人游艇至 Capri，探索码头别墅隐秘海湾，停留那不勒斯 Rione Sanita 区，欣赏 Caravaggio《七善行》真迹，高速列车至罗马。

**Episode 3 -- when in Rome...**
入住 Portrait Roma（Ferragamo 旗舰店上方），探索巴洛克教堂、Via Margutta，Trevi 喷泉、Pantheon、crema gelato，Vintage Fiat 500 夜游 Colosseum，Ferragamo 精品店导览。

**Episode 4 -- The plot thickens**
高速列车至威尼斯，Palazzo Venart 入住，San Marco 广场，Caffe Florian，Peggy Guggenheim 博物馆，Scala Contarini del Bovolo 烛光晚宴。

## 九、Get Lost（迷失体验）详细分析

### Hero 文案
"You need to Get Lost to find yourself"

### 核心概念
- 客户出发前完全不知道目的地
- 仅选择环境类型（Polar/Jungle/Desert/Mountain/Coastal）
- 可"掷骰子"完全随机
- 到达机场后才知道去哪里

### 7步流程
1. 匹配 Get Lost 旅行专家，确定"你想多迷失"
2. 选择环境（目的地未知）；可选"掷骰子"零输入
3. 地形针对性训练
4. 私人接送至首个目的地，配备装备
5. 探险行动团队后台追踪（隐形安全网）
6. what3words 技术导航至各签到点
7. 完成：庆祝仪式

### 定价

| 档位 | 每人价格（2人共享） |
|------|---------------------|
| Entry | £20,000 - £30,000 |
| Mid | £30,000 - £40,000 |
| High | £40,000 - £50,000 |
| Premium | £50,000 - £60,000 |
| Ultra | £60,000+ |

### 包含内容
全面的行程规划和设置、所有在地物流、世界级首席向导、当地支持团队、训练和技术装备、国内航班、住宿、大部分餐饮。

## 十三、对中国竞品的关键启示

1. **"情绪匹配"取代"目的地搜索"**：重新定义旅行搜索的入口，让客户从"我想去哪"变成"我想获得什么感受"。Feelings Engine 作为 AI + 情感的结合体，大幅降低了选择焦虑。

2. **原创IP矩阵形成品牌护城河**：10条原创产品线（Set Jetting、Get Lost、Blink 等）构成难以复制的差异化，其中 Set Jetting 尤其适合与影视文化输出结合。

3. **叙事化行程呈现**：使用 Episode（剧集）而非 Day（天数）来组织行程，文案采用文学/电影式的叙事口吻，配合影视取景地的故事线，让行程本身成为一场"剧"。

4. **透明定价 + "不收规划费"**：用"免费咨询、不收规划费"消除高端定制的不确定性顾虑。定价始终是"From X起"而非精确报价，同时通过 Get Lost 的分档定价建立了价格预期框架。

5. **双 CTA 策略**：首页"浏览行程库" vs "直接咨询定制"，覆盖不同决策阶段和性格类型的用户。Enquire Now 始终悬浮跟随。

6. **创始人 IP + 顶级媒体矩阵**：创始人出镜 + Forbes/CNBC/Conde Nast/Travel+Leisure/Bloomberg 等覆盖商业、旅行、生活方式的权威媒体背书，建立了极强的信任感。

7. **技术增强体验而非炫技**：AI 情绪引擎、what3words 野外导航、无人机航拍都是切实提升体验的技术手段，而非纯粹的营销噱头。

8. **多版本国际化架构**：UK/US/Rest of World 三站架构，自动检测 + 手动切换，支持双币种，为中国站全球化布局提供了参考。

9. **客户自助门户**：my.blacktomato.com 提供行程管理、文档查看等自助服务，减轻客服压力的同时提升客户掌控感。

10. **内容营销的全域覆盖**：从播客到视频，从旅行指南到文学性长篇文案，从月度旅行日历到情绪哲学，构建了完整的品牌内容生态。
