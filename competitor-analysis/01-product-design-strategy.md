## 1. 视觉设计方向：背景色策略（核心决策）

### 1.1 为什么所有西方高端旅行站都用浅色背景？

经过对 4 家西方竞品的实地分析，这不是巧合：

**原因一：白色 = 透明度 = 信任。** 西方高端旅行市场最大的信任障碍是"这个价格值不值"。白色背景在视觉上承诺"我没有暗处可以藏东西"——无论是 Black Tomato 不显价、Scott Dunn 不显价、还是 Kuoni 显示精确价格，白色都是统一选择。

**原因二：白色 = 摄影的画框。** 旅行品牌的核心视觉资产是目的地照片。白色/浅色背景像一个展墙——马尔代夫的蓝更鲜活、非洲草原的金更有层次、京都枫叶的红更浓烈。暗色背景会压缩照片的视觉表现力。

**原因三：白色 = 信息的画布。** 旅行站需要承载酒店照片、行程文字、价格数字、地图图表、用户照片、合作伙伴 logo——白色是唯一能兼容所有这些内容类型的底色。暗色背景在展示酒店照片（往往本身就偏暗）时会丢失细节。

**原因四：西方"安静的奢华"（Quiet Luxury）审美传统。** Loro Piana、The Row、Brunello Cucinelli 都使用大量白色/米色空间。这不是"西方人就喜欢白色"，而是白色让产品（在这里是目的地照片）自己说话。

### 1.2 赞那度的暗色调：模仿酒店品牌，而非旅行品牌

赞那度的视觉参照系是 Aman、Rosewood、Six Senses——这些是**酒店品牌**，不是旅行品牌。

- 酒店网站卖的是**一个产品**（酒店本身，物理空间，通常偏暗/有氛围感）
- 旅行网站卖的是**多种产品**（海滩/雪山/沙漠/丛林——全部在不同光照条件下）

赞那度在 2012 年品牌初创时，中国"高端旅行定制"品类完全空白，它用"暗色调 = 奢华酒店 = 高端"这条最短路径建立视觉信任。但 2026 年的新创品牌不应该复刻 14 年前的策略——目标客户的视觉素养已经完全不同。

**结论：赞那度的暗色调是品牌初创期的"借势"策略，不是旅行品牌的最佳视觉表达。**

### 1.3 白色在中文市场的风险与对策

| 风险 | 对策 |
|------|------|
| 白色 = OTA = "不高端" | 用间距和密度区分。携程是"填满信息的白色"，我们是"留白的白色" |
| 白色显得"冷" | 用米白 `#FAFAFA` 而非纯白 `#FFFFFF`，配合暖色摄影和铜色点缀 |
| 白色不能做"炫耀型消费"刺激 | 旅行的视觉载体是目的地本身——白色是放映颜色的银幕，不是主角 |

### 1.4 最终决策

**主色体系：米白/浅灰（`#FAFAFA`），深海军蓝（`#0A1628`）仅用于 Hero 区和 Footer 区。**

| 区域 | 背景色 | 理由 |
|------|--------|------|
| 全场背景 | `#FAFAFA` | 信息画布，让摄影说话 |
| 卡片 | `#FFFFFF` | 微提亮，建立视觉层次 |
| Hero 区 | `#0A1628` | "启程前的沉静仪式感" |
| Footer 区 | `#0A1628` | 收束视觉，牌照白字清晰 |
| 情绪升温模块 | `#F5F0EB` | 限量/至臻精选等需要情绪升温的区段 |
| 悬浮 CTA 栏 | `rgba(10, 22, 40, 0.95)` | 与浅色全场形成"行动召唤"对比 |

## 3. 网站信息架构

### 3.1 首页模块层次

```
1. 导航栏（透明→滚动后白底）
2. Hero 区（100vh，深海军蓝）
3. 信任条（牌照+酒店品牌+媒体）
4. 客群快速入口（亲子/情侣/独行/银发）
5. 情绪引擎（5种情绪→匹配行程）
6. 签名 IP 产品线（6张竖版大片卡片）
7. 精选旅程（From ¥XX,XXX起/人）
8. 专家团队（目的地专家体系）
9. 定制流程可视化（4步+时间承诺）
10. 客户故事（轮播）
11. 底部转化区（三选一CTA）
12. Footer（完整牌照体系）
```

### 3.2 导航结构

```
一级导航（4项）：
├── 目的地（按大洲分组）
├── 旅行形态（7大产品线+IP矩阵）
├── 灵感（情绪引擎+旅行日历+故事）
└── 关于（品牌+团队+为什么选我们）
```

### 3.3 详情页结构（11模块中式骨架）

1. Hero 大图区（纯图，不叠字）
2. 标题 + 价格区（双档位+免责）
3. 行程亮点前置（3-4个图标）
4. Sticky Tab 导航（行程|酒店|费用|须知|评价）
5. 每日行程轴（Close All/Expand All，Audley 模式）
6. 酒店信息（具名+照片+200字介绍）
7. 费用包含/不含（✅❌双列对比）
8. 预订须知（手风琴折叠）
9. FAQ（Kuoni式专家署名）
10. 客户评价
11. 底部悬浮CTA栏（微信咨询+电话咨询）

### 3.4 信任锚点体系

| 锚点 | 对标携程 | 核心内容 |
|------|---------|---------|
| 安心行 | 放心飞/行 | 专车、航司直签、航班应急预案 |
| 稳心住 | 放心住 | 实地考察、品牌直签 |
| 贴心伴 | 放心玩 | 中文司导24/7、医疗援助 |
| 透明价 | 放心付 | 无隐藏费用、退改公开 |
| 随心改 | 退订保障 | 30天免费改期、不可抗力全退 |

Footer 法定锚点：旅行社牌照 + ICP + 公安备案 + 400热线 + 12345 + 微信二维码

## 4. 内容策略

### 4.1 行程文案：70%散文体 + 30%功能信息

四种散文模式（基于赞那度+Black Tomato分析）：

1. **自然描写型** — 适用于自然/风光目的地
2. **历史叙事型** — 适用于文化遗产/古城
3. **情感共振型** — 适用于蜜月/纪念旅行
4. **文化引述型** — 适用于文学/哲学底蕴深厚的目的地

文案规则：每天≤200字、3句换段、每句≤40字、必须有至少1个具体数字/地名/人名

### 4.2 酒店介绍模板

```
【酒店名称】（英文名/品牌名）
[一句话定位] · 开业/翻新年份 · X间客房
[核心描述：位置+建筑+景观]
[具体细节：床品/备品/设施/餐饮]
我们的推荐理由：
- 功能理由
- 体验理由
- 硬件理由
```

### 4.3 品牌语料库

| 用途 | 文案 |
|------|------|
| 品牌标语 | 属于你的世界旅程 |
| 英文标语 | Journeys That Are Unmistakably Yours |
| 价值主张 | 不卖行程，只设计经历 |
| CTA通用 | 与顾问对话 → |
| 价格后缀 | ¥XX,XXX 起/人 · 参考价 · 个性化定制后确认 |
| 规划承诺 | 咨询免费，方案无限制修改 |

### 4.4 产品标签词汇表（四字格体系）

```
体验等级：至臻精选 / 独家定制 / 限量发售 / 首发热线
行程调性：深度人文 / 非遗体验 / 亲子研学 / 美食巡礼 / 避世海岛 / 自然野奢
稀缺权益：非开放区域 / 闭馆后独享 / 私人飞机接驳 / 仅限N席
服务承诺：中文管家 / 全程陪同 / 24H支持 / 无购物 / 纯玩定制
```

## 5. 转化路径设计

### 5.1 CTA 策略：咨询制为主

| 产品类型 | 转化模式 |
|---------|---------|
| 私人定制 | 纯咨询 |
| 臻选小团 | 咨询为主 + 在线锁定位置 |
| 别墅行馆 | 咨询为主 |
| 亲子时光 | 咨询为主 |
| 酒店预订 | 在线预订（"前台现付"模式）|
| 企业高定 | 纯咨询 + 招投标 |

### 5.2 咨询流程

1. **需求提交**（1分钟）：目的地+人数+时间+预算5档+特别需求
2. **首次响应**（24小时内，工作时间2小时）
3. **方案呈现**（1-3个工作日，PDF格式）
4. **确认与付款**（定金30%，出发前45天付清）

### 5.3 微信生态整合

| 触达点 | 功能 |
|--------|------|
| 服务号 | 产品展示+咨询入口+模板消息 |
| 订阅号 | 旅行故事+灵感种草 |
| 视频号 | 目的地短视频+直播 |
| 小程序 | 行程浏览+需求提交+订单管理 |
| 企业微信 | 顾问1v1沟通+文件发送+签约 |

每个产品详情页标配"分享到微信"按钮，生成朋友圈竖版海报。
