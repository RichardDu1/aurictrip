# 面向中国人的高端全球旅行网站 — 西式设计 × 中式结构 参考手册

> 提取自 OuluTrip 项目竞品分析（2026-07）
> 目标项目：面向中国人的全球高端旅行定制站
> 核心策略：**西式设计元素做视觉皮 + 中式页面结构做转化骨架**

---

## 0. 为什么是这个组合？

面向中国人的高端旅行站，不能照搬任何一边：

- **纯西式设计**（如 Black Tomato/Scott Dunn）：视觉高级，但缺价格、缺费用清单、缺酒店具名——中国客户会感到信息不透明，不敢决策。
- **纯中式设计**（如开元周游/携程）：信息全但视觉拥挤，"大卖场感"重，撑不起高端定位。

**正确组合**：用西方高端站的视觉语言建立"高级感"信任，用中文竞品的页面结构满足"配置式决策"需求。

这不是折中，是文化决策模式差异决定的——西方客户是"信任式决策"（故事→顾问→问价），中国客户是"配置式决策"（看价→看人→看酒店→看包含）。**砍中式结构元素 = 丢转化。**

## 一、西式设计元素（视觉皮）— 可直接照搬

以下设计元素来自 4 家英文高端旅行站（Black Tomato / Scott Dunn / Audley Travel / Kuoni）的实地研究。

### 1.1 色彩体系

| 元素 | 西式做法 | 落地建议 |
|------|---------|---------|
| 主背景 | 米白/暖灰为主场（`#FAFAFA`），深色仅用于 hero 区 | 全局背景米白，深海军蓝只给 hero 和 footer |
| 品牌色 | 香槟金/铜色（`#C9A96E`），用量克制，不做实心大按钮 | 品牌色只用于文字链接、下划线、小装饰，不铺满 |
| 卡片 | **无边框、无阴影**，靠留白和分割线区分 | `border: none; box-shadow: none;` 纯白底 + 间距 |
| 按钮 | 文字链接 + 下划线箭头（`Explore →`），非实心色块 | 主 CTA 用文字链接式，辅 CTA 用细线边框 |

### 1.2 字体体系

| 元素 | 西式做法 | 落地建议 |
|------|---------|---------|
| 标题 | Playfair Display / Cormorant Garamond 等衬线体 | `--font-serif: 'Playfair Display', 'Noto Serif SC', serif` |
| 正文 | Inter / Lato 等无衬线体，中文用思源黑体 | `--font-sans: 'Inter', 'Noto Sans SC', sans-serif` |
| 行程正文 | **衬线大字 + 宽行距 + 大量留白**，像杂志正文 | `font-size: 1.125rem; line-height: 2; max-width: 680px` |
| 数字/价格 | 衬线体，不做电商式加粗巨大 | 小字灰字，不抢视觉权重 |

### 1.3 摄影与视觉调性

- **Editorial Reportage 调性**：像国家地理杂志的纪实摄影，不是旅行社广告图
- **全屏大图**做 hero 背景，但图上**不叠文字**（标题/价格移到图下方留白区）
- 图片色调偏暖、低饱和、有"故事感"，避免高饱和电商风

### 1.4 轮播与动效

- 轮播节奏**慢**（7-8 秒切换，淡入淡出），不是 3 秒快速翻页
- 轮播数量**少**（3-5 张精选），不是堆砌
- 不用自动播放视频、不用倒计时、不用闪烁标签

### 1.5 留白与密度

- 区段间距大（`py-24` 或更大），不用紧凑排列
- 每个区段只传达一个核心信息
- 文字密度低——一段不超过 3 行，一屏不超过 2 个信息块

### 1.6 西式竞品设计特征速查表

| 品牌 | Hero 形态 | 价格策略 | CTA 风格 | 卡片风格 | 最值得学的 |
|------|----------|---------|---------|---------|-----------|
| **Black Tomato** | 动画叙事首页 | 完全不显价 | `Enquire Now` | 大图+标题极简 | 摄影调性、情感叙事 |
| **Scott Dunn** | 单图+4 个文字 CTA | 完全不显价 | `Plan Your Holiday` | 客群切片卡片 | 按客群切首页 |
| **Audley Travel** | 3 张目的地轮播 | Guide price + 免责 | `Enquire now` | 图/标题/一行描述 | 目录骨架+精选轮播 |
| **Kuoni** | 3 张目的地轮播 | `From £1,849 p/p` | `Send an enquiry` | 图/标题/价格/日期 | 指导价呈现方式 |

## 二、中式页面结构（布局骨架）— 必须保留

以下结构元素来自中文竞品研究（赞那度 / 鸿鹄逸游 / 穷游 / 携程），是中文客户"配置式决策"的硬需求。

### 2.1 详情页必须有的结构模块

按从上到下的顺序：

```
1. Hero 大图区（纯图，不叠字）
2. 标题 + 价格区（标题 + ¥XX,XXX 起/人 + 指导价免责后缀）
3. 人数选择器 + 日期选择（可选，中高端可加）
4. Sticky Tab 导航（行程安排 | 费用说明 | 酒店信息 | 预订须知）
5. 行程亮点前置（3-4 个大图标 + 一句话，在详细行程前）
6. 每日行程轴（Day 1 / Day 2 ... 垂直时间线，展开/折叠）
7. 酒店信息（具名 + 每家 50-100 字介绍，中式客户把酒店当卖点）
8. 费用包含 / 不含（✅❌ 双列对比，不是一段文字）
9. 预订须知 + 退改政策（手风琴折叠）
10. FAQ 手风琴
11. 底部悬浮 CTA 栏（价格 + "与顾问对话"按钮）
```

### 2.2 价格呈现的三级体系

| 层级 | 做法 | 依据 |
|------|------|------|
| **首页/Hero** | **不显价** | Black Tomato/Scott Dunn 都不显 |
| **列表页** | 小字灰字 `¥XX,XXX 起 · 指导价` | 弱化但存在，做前置筛选 |
| **详情页** | 显价 + 人数算价 + 免责后缀 | 赞那度模式：`参考价，将根据出行人数和季节有所差别` |

### 2.3 信任锚点清单（中文市场必须）

中文客户的信任来自**机构资质**而非"顾问个人经历"：

| 必须项 | 说明 |
|--------|------|
| 公司注册号 / 旅行社许可证编号 | 赞那度：`L-BJ-CJ00559`，这是法定信任锚点 |
| ICP 备案号 | 中文网站底线 |
| 400 电话 / 中国客服号 | 中文客户硬预期，缺了显"不正规" |
| 7×24 救援承诺 | 携程"放心玩"体系，中文高端客户强需求 |
| ATOL/ABTA（如适用） | 国际公认信任锚点 |
| 真实评价 + 团号绑定 | 开元周游模式，比匿名评价可信 10 倍 |

### 2.4 中文高端包装语料

| 用途 | 用词 | 来源 |
|------|------|------|
| 产品分级标签 | `独家定制` `至臻精选` `深度人文` | 赞那度四字格 |
| 主题切片导航 | `深度人文` `非遗体验` `亲子研学` `美食巡礼` `避世海岛` | 鸿鹄逸游 |
| 栏目命名 | `地球研习社` `轻年计划` 式品牌栏目名 | 穷游 |
| 保障体系 | `安心行` `稳心住` `贴心导`（文学化命名，非"放心 X"） | 携程结构 + 文学化 |
| 稀缺表达 | `闭园后独享` `仅限 X 组`（具体权益，非抽象 `not templates`） | 赞那度 |
| CTA 文案 | `与顾问对话 →` 或 `微信咨询 →` | 去交易感 |

### 2.5 中文详情页文案特征

- **散文体叙事**（非功能罗列）：`晨光初綻，您的專屬管家已駕駛豪華私家專車靜候`
- **具象物质符号 + 文化符号**：中国客户吃"可识别的符号确认档次"——`Tiffany蓝`、`米其林三星`、`文华东方`、`里维埃拉爵士`
- **酒店即产品**：每家酒店具名 + 50-200 字介绍，不是"住宿：四星级酒店"一笔带过
- **"分享到微信朋友圈"按钮**：中式社交获客，几乎零成本

## 三、中西结合的落地分寸

### 3.1 可以完全西化的（不改不影响转化）

- 色彩体系（米白底 + 香槟金点缀）
- 字体选择（衬线标题 + 无衬线正文）
- 摄影调性（editorial reportage）
- 留白密度（大间距、低信息密度）
- 卡片风格（无边框无阴影）
- 轮播节奏（慢、少、淡入）

### 3.2 必须保持中式的（改了会丢转化）

- 显式价格 + 人数算价 + 免责后缀
- 费用包含/不含双列清单
- 酒店具名 + 介绍
- Sticky Tab 导航（行程/费用/酒店/须知）
- 底部悬浮 CTA 栏
- 信任锚点（牌照/ICP/400/救援）
- "分享到微信"按钮
- 起价说明免责条款

### 3.3 设计 token 参考值

```css
:root {
  /* 西式色彩 */
  --color-primary: #C9A96E;        /* 香槟金，用量减半 */
  --color-dark-bg: #0A1628;        /* 深海军蓝，仅 hero/footer */
  --color-light-bg: #FAFAFA;       /* 米白主场 */
  --color-text: #1a1a1a;
  --color-text-muted: #6b7280;     /* 灰色用于价格/辅助信息 */

  /* 西式字体 */
  --font-serif: 'Playfair Display', 'Noto Serif SC', serif;
  --font-sans: 'Inter', 'Noto Sans SC', sans-serif;

  /* 西式间距 */
  --section-gap: 6rem;             /* 区段间距大 */
  --content-max-width: 680px;      /* 正文窄栏阅读 */

  /* 西式卡片 */
  --card-shadow: none;
  --card-border: none;
  --card-radius: 0;
}
```

### 3.4 竞品对照：赞那度是最好的"中西结合"参考

赞那度是中文高端站里最西化的——视觉干净、衬线字体、大图留白。但它的布局完全是中式的：显价 + 人数选择器 + 费用包含 + 酒店具名 + 分享微信 + 起价免责。**它证明了西式视觉皮 + 中式结构骨架是成立的。**

OuluTrip 改造计划中的结论直接适用于全球高端站：
> 设计元素可靠拢西方，整体布局必须偏中国人习惯。这不是折中，是文化决策模式差异。

## 四、分阶段落地建议

### 阶段 1：视觉皮替换（最快见效）
- 全局 CSS token 调整（色板、字体、间距、卡片去阴影）
- 按钮从实心色块改为文字链接 + 下划线箭头
- 详情页 hero 图不叠字

### 阶段 2：中式结构补全
- Sticky Tab 导航（行程 | 费用 | 酒店 | 须知）
- 费用包含/不含双列 ✅❌ 对比
- 每日行程垂直时间轴
- 底部悬浮 CTA 栏

### 阶段 3：信任体系搭建
- Footer 加牌照/ICP/400/救援承诺
- 酒店具名 + 介绍
- "分享到微信"按钮
- 起价说明免责条款

### 阶段 4：语料升级
- 四字格产品分级标签
- 行程文案向赞那度散文体靠拢
- 补具象物质/文化符号（酒店名/米其林/brand/文化典故）

## 附：中西决策模式对比速查

| 维度 | 西方高端 | 中国东部高端 |
|------|---------|-------------|
| 决策路径 | 信任式：故事→信顾问→问价 | 配置式：看价→看人→看酒店→看包含 |
| 价格 | 不显/guide price 一句带过 | 显 ¥X 起/人 + 人数算价 + 免责 |
| 酒店 | narrative 一句带过 | 多家并列 + 200 字，酒店即卖点 |
| 费用明细 | 无清单 | 必有"包含/不含"两 tab |
| 文案调性 | 抽象情感（`Pursuit of Feeling`） | 具象物质 + 文化符号（`Tiffany蓝`） |
| 信任来源 | 顾问人格 + 奖项 | 牌照 + 酒店 brand + 米其林背书 |
| 分享 | 无 | `分享到微信朋友圈` |
| 稀缺表达 | `not templates` 抽象 | `独家定制` + 具体权益 |
