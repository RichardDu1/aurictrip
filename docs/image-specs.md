# 图片规格指南 · AuricTrip

## 设计原则

- 所有图片使用**高压缩率 JPEG** 或 **WebP**（优先 WebP）
- 不允许图片上叠加文字
- 不允许过度调色——自然饱和度比高饱和度更高级
- 氛围优先于信息密度

## 文件命名规则

```
[page]-[section]-[descriptor].webp
```

示例：
- `journey-hero-tuscany.webp`
- `hotel-rosewood-tuscany.webp`
- `home-hero-main.webp`

## 优化参数

| 参数 | 值 |
|------|-----|
| WebP 质量 | 75% |
| 最大文件大小 | 300KB（普通图）/ 500KB（Hero 图） |
| 色彩空间 | sRGB |
| 元数据 | 全部移除（除版权外的 Exif） |

## 摄影风格方向

- **景别**：宽构图、景深感强的环境肖像
- **光线**：自然光、侧光、逆光（金色时刻优先）
- **色调**：暖色为主（与 Auric Gold 协调），避免高饱和
- **人物**：少出现或不出现正脸，用剪影和背影增加想象空间
- **情绪**：安静、庄严、有呼吸感——不是"刺激"，是"沉浸"
